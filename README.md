## 🇬🇧 English

A simple, offline chess game for Android built with HTML/CSS/JS.

### Features
- Complete piece movement (pawn, knight, bishop, rook, queen, king)
- Short and long castling
- Pawn promotion
- Check, checkmate and stalemate detection
- 100% offline — no internet required
- No ads, no trackers, no unnecessary permissions
- Minimalist touch interface

## 🇪🇸 Español

Un juego de ajedrez simple y offline para Android hecho con HTML/CSS/JS.

### Características
- Movimiento completo de todas las piezas (peón, caballo, alfil, torre, dama, rey)
- Enroque corto y largo
- Promoción de peón
- Detección de jaque, jaque mate y tablas
- 100% offline — no requiere internet
- Sin publicidad, sin rastreadores, sin permisos innecesarios
- Interfaz táctil minimalista
